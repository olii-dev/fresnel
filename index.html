    Browsers can't read Wi-Fi internals (RSSI, channel, band, noise). fresnel measures what the connection actually does: HTTP round trips to Cloudflare's nearest edge (resource-timing precise, server time subtracted) and to Google, probe loss (no reply within 2 s), multi-stream throughput, latency under load (bufferbloat), DNS-over-HTTPS resolver timing and the cold connection breakdown. Loss here is application-level: a lost probe means the link stalled long enough that a request got no answer in 2 s, which is exactly what "iffy" feels like.
